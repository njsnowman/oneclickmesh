# Data sources and interpretation

- **Elevation:** USGS 3D Elevation Program (3DEP) ImageServer, bare-earth elevation raster.
- **Address geocoding:** U.S. Census Geocoder.
- **Public nodes:** MeshCore public node feed, filtered by the entered radio profile where supported.
- **Map context:** USGS National Map layers and Esri street-map tiles; Street View links open in Google Maps when available.
- **Propagation:** NTIA Institute for Telecommunication Sciences (ITS) Irregular Terrain Model (ITM) v1.4 native library.

Input sources may be unavailable, updated, or incomplete. Cache timestamps describe when One Click Mesh retrieved a file, not when terrain or map imagery was surveyed. See the report's source and assumptions pages for the values used in each run.

Predicted samples are model estimates at discrete locations. They do not guarantee continuous coverage. Verify coordinates and antenna heights, use the correct hardware parameters, and measure two-way performance in the field. Buildings, foliage, local interference, antenna/cable losses, and multi-hop routing are not fully represented by a direct-path propagation prediction.
